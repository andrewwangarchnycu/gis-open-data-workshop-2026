# Exercise 04 — The One Map Challenge 一張地圖挑戰
*5 minutes to brief, take-home to complete 說明 5 分鐘，成果可課後完成*

The capstone deliverable of the workshop. Everything before this exercise feeds into it.
本工作坊的最終成果。前面所有練習都匯集於此。

## Deliverable 成果要求

```text
1 Research Question   一個研究問題
+ 1 Spatial Analysis  一次空間分析
+ 1 Research Map      一張研究地圖
+ 1 Spatial Insight   一個空間洞見
```

## Example 範例

> **Where are the greener public spaces?** 哪裡是較綠意盎然的公共空間？

Possible datasets 可能資料集: trees, buildings, public spaces, roads 樹木、建築、公共空間、道路

Possible analysis 可能分析: tree density within public spaces 公共空間內的樹木密度

**Want to skip straight to real data?** [`case-studies/01-green-coverage-grid/`](../../case-studies/01-green-coverage-grid/) runs this exact example on real Taipei street-tree data, no registration required — a ready-made starting point if you'd rather adapt real data than build your own sample.
**想直接使用真實資料？** [`case-studies/01-green-coverage-grid/`](../../case-studies/01-green-coverage-grid/) 以真實的台北市行道樹資料執行這個範例，無需申請帳號——若你想直接調整真實資料而非自建範例，這是現成的起點。

## Steps 步驟

1. **Question** — reuse or refine your question from [Exercise 01](../01_data_exploration/). 沿用或精煉[練習 01](../01_data_exploration/)中的問題。
2. **Analysis** — reuse your result from [Exercise 03](../03_spatial_analysis/), or run a new one in [`notebooks/04_mini_research.ipynb`](../../notebooks/04_mini_research.ipynb) or QGIS. 沿用[練習 03](../03_spatial_analysis/)的結果，或於筆記本／QGIS 中重新執行。
3. **Insight** — push your result through the What/Where/Why/So-what chain from [Lesson 06](../../lessons/06-spatial-insight/). 將結果套入[課程 06](../../lessons/06-spatial-insight/)的四問鏈。
4. **Map** — design the final graphic following [Lesson 07 — Research Map Design](../../lessons/07-research-map-design/) and [`resources/map-design/research-map-checklist.md`](../../resources/map-design/research-map-checklist.md). 依[課程 07](../../lessons/07-research-map-design/)與檢查清單設計最終圖面。

## Required map elements 地圖必要元素

- [ ] Title (states the question) 標題（陳述問題）
- [ ] Main map 主要地圖
- [ ] Legend 圖例
- [ ] Data source 資料來源
- [ ] Annotation highlighting the key finding 標註關鍵發現
- [ ] One stated insight (a sentence, not just the map) 一段陳述洞見的文字（不只是地圖本身）

## Submitting 繳交方式

Add your final map (PNG or PDF) and a short write-up (question + insight, 3–5 sentences) to [`examples/student_examples/`](../../examples/student_examples/), named `yourname_topic.png` and `yourname_topic.md`.
將最終地圖（PNG 或 PDF）與簡短說明（問題＋洞見，3–5 句）新增至 [`examples/student_examples/`](../../examples/student_examples/)，命名為 `yourname_topic.png` 與 `yourname_topic.md`。

See finished examples for inspiration: [`examples/research_maps/`](../../examples/research_maps/).
參考已完成範例：[`examples/research_maps/`](../../examples/research_maps/)。
