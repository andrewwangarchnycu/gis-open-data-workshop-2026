# Exercise 01 — Data Exploration 資料探索練習

Pairs with [Lesson 03 — Finding Open Geospatial Data](../../lessons/03-open-geospatial-data/) and [`notebooks/01_open_data.ipynb`](../../notebooks/01_open_data.ipynb).

## Task 任務

1. Write down a spatial research question about a place you know. 寫下一個關於你熟悉地點的空間研究問題。
2. Fill in the chain: 填入以下鏈：

   ```text
   Research Question 研究問題: ___________________________
   Required Variables 所需變數: ___________________________
   Potential Dataset 可能資料集: ___________________________
   Data Source 資料來源: ___________________________
   ```

3. Find one real open dataset matching your source (OpenStreetMap, a government open-data portal, or an API — see [`resources/open-data/`](../../resources/open-data/)). 找出一個符合你資料來源的真實開放資料集。
4. Note: 記錄以下資訊：
   - Format (GeoJSON, CSV, Shapefile…) 格式
   - CRS (if stated) CRS（若有標示）
   - License 授權條款
   - Spatial/temporal coverage 空間／時間涵蓋範圍

## Deliverable 成果

A short written summary (5–8 sentences) of your question and the dataset you found, ready to load into QGIS in [Exercise 02](../02_qgis/).
一份簡短書面摘要（5–8 句），說明你的問題與找到的資料集，準備於[練習 02](../02_qgis/)中載入 QGIS。
