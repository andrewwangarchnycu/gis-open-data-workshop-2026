# Exercise 02 — QGIS Practice QGIS 練習

Pairs with [Lesson 04 — QGIS Basics](../../lessons/04-qgis-basics/) and [`qgis/`](../../qgis/).

## Task 任務

Using either the workshop sample data or your own dataset from [Exercise 01](../01_data_exploration/):
使用工作坊範例資料，或[練習 01](../01_data_exploration/)中你自己的資料集：

1. Load the data into QGIS. 將資料載入 QGIS。
   → [`qgis/01_basics/loading-geojson.md`](../../qgis/01_basics/loading-geojson.md) or [`loading-csv.md`](../../qgis/01_basics/loading-csv.md)
2. Inspect the attribute table and confirm your key variable is present. 檢視屬性表並確認關鍵變數存在。
   → [`qgis/01_basics/attribute-tables.md`](../../qgis/01_basics/attribute-tables.md)
3. Check and, if needed, fix the CRS. 檢查並在需要時修正 CRS。
   → [`qgis/01_basics/crs.md`](../../qgis/01_basics/crs.md)
4. Apply a filter relevant to your question. 套用與你問題相關的篩選。
   → [`qgis/01_basics/filtering.md`](../../qgis/01_basics/filtering.md)
5. Create a buffer, spatial join, or intersection — whichever answers your question. 建立緩衝區、空間 join 或交集——擇一能回答你問題的操作。
   → [`qgis/02_analysis/`](../../qgis/02_analysis/)
6. Apply basic symbology to visualize the result. 套用基本符號化以視覺呈現結果。
   → [`qgis/03_map_design/symbology.md`](../../qgis/03_map_design/symbology.md)

## Reflection 反思

For each operation you used, write one sentence in the form:
針對你使用的每個操作，以下列句型寫一句話：

> "I used [tool] because I wanted to know [spatial meaning], to answer [research question]."
> 「我使用了［工具］，因為我想知道［空間意義］，以回答［研究問題］。」

## Deliverable 成果

A QGIS project file (or a screenshot) showing your filtered/analyzed layer with basic symbology applied, plus your reflection sentences.
一份 QGIS 專案檔（或截圖），呈現套用基本符號化後的篩選／分析圖層，附上你的反思句子。
