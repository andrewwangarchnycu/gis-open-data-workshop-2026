# Exporting Maps 匯出地圖

**Why 為什麼**: your research map only communicates once it leaves QGIS — as an image or PDF for a report, presentation, or the One Map Challenge submission.
研究地圖唯有離開 QGIS 之後才能真正傳達內容——成為報告、簡報或「一張地圖挑戰」繳交用的圖片或 PDF。

## From the Layout Manager 從版面配置管理員匯出

1. With your layout open, go to `Layout → Export as Image…` for PNG/JPEG, or `Layout → Export as PDF…` for print-quality output. 開啟版面配置後，選擇「版面配置 → 匯出為影像」（PNG／JPEG）或「匯出為 PDF」（適合印刷品質）。
2. Set **Export resolution** to at least `300 dpi` for anything meant to be printed or zoomed into. 若用於列印或放大檢視，將匯出解析度設為至少 300 dpi。
3. Choose a destination and file name — use a descriptive name, e.g. `tree-density-research-map.png`. 選擇儲存位置與檔名，建議使用具描述性的名稱。

## Format guide 格式選擇

| Format 格式 | Use for 適用於 |
|---|---|
| PNG | Web, slides, GitHub README 網頁、簡報、GitHub README |
| PDF | Print, precise vector quality at any zoom 列印、任意縮放皆保有向量精度 |
| SVG | Further editing in Illustrator/Inkscape 於 Illustrator／Inkscape 進一步編輯 |

再次檢查 [`resources/map-design/research-map-checklist.md`](../../resources/map-design/research-map-checklist.md)。匯出是最後一步，並非設計檢視的替代方案。
