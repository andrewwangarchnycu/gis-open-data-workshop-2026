# Student Examples 學生範例

Submissions from the [One Map Challenge](../../exercises/04_one_map_challenge/). This is where past learners' final maps live, as inspiration for future workshops.
[一張地圖挑戰](../../exercises/04_one_map_challenge/)的繳交成果存放於此，作為未來工作坊學習者的參考範例。

## Submission format 繳交格式

For each submission, add two files with a matching name: 每份繳交新增兩個同名檔案：

- `yourname_topic.png` (or `.pdf`) — the final research map 最終研究地圖
- `yourname_topic.md` — a short write-up: 簡短說明：

```markdown
# [Your Title] 你的標題

**Question 問題**: ...

**Method 方法**: (e.g. buffer + spatial join in QGIS / GeoPandas)

**Insight 洞見**: ...

**Author 作者**: Your name, workshop date
```

## Why this folder matters 這個資料夾的意義

Seeing real, imperfect, learner-made maps is often more useful than seeing only polished professional examples — it shows what's achievable in one 2-hour workshop. 看見真實、不完美、由學習者完成的地圖，往往比只看精緻的專業範例更有幫助——展現在一場 2 小時工作坊中能做到的成果。
