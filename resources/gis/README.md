Beginner-friendly references for concepts and tools introduced in this workshop.
本工作坊所提及概念與工具的初學者友善參考資源。

## Concepts 概念

- [Lesson 02 — From Space to Data](../../lessons/02-space-to-data/) — vector/raster, point/line/polygon, attributes, CRS 向量／網格、點線面、屬性、CRS
- [QGIS Documentation](https://docs.qgis.org) — official manual 官方手冊
- [QGIS Training Manual](https://docs.qgis.org/latest/en/docs/training_manual/) — free, structured intro course 免費、結構化入門課程

## Coordinate reference systems CRS

- [epsg.io](https://epsg.io) — look up any CRS by code or search 依代碼或搜尋查詢任意 CRS
- Common CRS used in this workshop 本工作坊常用 CRS:
  - `EPSG:4326` — WGS84, standard lon/lat, for storage/sharing 標準經緯度，用於儲存／分享
  - `EPSG:3826` — TWD97 / TM2 zone 121, metric, for Taiwan-based measurement 公尺制，適用於台灣地區測量
