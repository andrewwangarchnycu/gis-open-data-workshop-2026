# Visual Hierarchy 視覺層級

**Core question 核心問題**: What should the viewer see first? 觀者應該先看到什麼？

Decide this deliberately, before you design anything. If everything is emphasized, nothing is.
在開始設計前先刻意決定這件事。若每樣東西都被強調，就等於沒有重點。

## The typical order 典型順序

1. **The main spatial pattern** — the finding itself (e.g. a color gradient showing density) 主要空間樣式——發現本身（例如呈現密度的色彩漸層）
2. **The annotation** — pointing directly at the key location 標註——直接指向關鍵位置
3. **The title** — states the question 標題——陳述問題
4. **Legend, scale, source** — supporting reference information 圖例、比例尺、來源——輔助性參考資訊

Most beginners get this backwards — making the title huge and the actual finding visually quiet. Reverse that.
多數初學者會弄反順序——把標題做得很大，實際發現反而不顯眼。應該反過來。

## Techniques 技巧

- **Size** — the most important element should not be the smallest thing on the page. 最重要的元素不該是頁面上最小的東西。
- **Contrast** — the key finding should have the highest contrast against its background. 關鍵發現與背景的對比應最高。
- **Isolation** — surround important elements with whitespace so the eye lands there first. 在重要元素周圍留白，讓視線優先落在該處。
- **Color saturation** — reserve your most saturated color for the thing that matters most; keep context muted. 將最飽和的顏色留給最重要的內容，脈絡背景則使用較低飽和度。

## Quick test 快速測試

Squint at your map (or blur it) for two seconds. What's the first shape/color you notice? If it's not your key finding, revise.
瞇眼看（或模糊化）你的地圖兩秒，你最先注意到的形狀／顏色是什麼？若不是你的關鍵發現，就需要修改。
