# Research Map Checklist 研究地圖檢查清單

Run every map through this before calling it done — for the [One Map Challenge](../../exercises/04_one_map_challenge/) or any research output.
在完成任何地圖前（[一張地圖挑戰](../../exercises/04_one_map_challenge/)或其他研究產出）都用這份清單檢查一次。

```text
□ Does the map answer a question?
  地圖是否回答了一個問題？
□ Is the main spatial pattern obvious?
  主要空間樣式是否一目了然？
□ Is there a clear visual hierarchy?
  是否有清楚的視覺層級？
□ Is color encoding meaningful?
  色彩是否傳達有意義的資訊？
□ Is the legend understandable?
  圖例是否易於理解？
□ Is typography readable?
  字體排印是否易讀？
□ Is unnecessary information removed?
  是否已移除不必要的資訊？
□ Is the study area clear?
  研究範圍是否清楚？
□ Is the data source documented?
  資料來源是否有記載？
□ Is the key insight visible?
  關鍵洞見是否清楚可見？
```

## How to use this 使用方式

Go through each line as a literal yes/no. Any "no" means revise before submitting — not "note for later."
逐項以是／否檢查，任何一項「否」都代表需修改後才能繳交，而非「之後再說」。
