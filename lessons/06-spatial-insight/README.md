# 06 — From Data to Spatial Insight 從資料到空間洞見
*15 minutes 分鐘*

A computed result is not an insight. This module is the bridge between "I ran an analysis" and "I learned something."
運算結果本身不是洞見。本模組是「我完成了一次分析」與「我發現了某件事」之間的橋樑。

```text
Data 資料
↓
Pattern 樣式
↓
Relationship 關係
↓
Interpretation 詮釋
↓
Insight 洞見
```

## The four questions 四個問題

Push every result through these, in order:
把每個結果依序推過這四個問題：

### What? 是什麼？
What does the data literally show? Describe the pattern without interpreting it yet.
資料具體顯示了什麼？先描述樣式，還不要詮釋。
> "60% of public spaces have no tree within 10m; 40% do." 「60% 的公共空間 10 公尺內無樹木；40% 有。」

### Where? 在哪裡？
Where does the pattern concentrate or vary? Is it clustered, edge-located, uniform?
樣式集中或變化於何處？是聚集、位於邊緣，還是均勻分布？
> "The tree-poor spaces cluster in the older, denser district." 「缺乏樹木的空間集中於較舊、密度較高的區域。」

### Why? 為什麼？
What might explain the pattern? This is a hypothesis, grounded in what you know about the place — not yet proven.
什麼可能解釋這個樣式？這是一個根植於你對該地認識的假設，尚未證實。
> "That district was built before street-tree planting requirements existed." 「該區域是在行道樹種植規範出現之前建成的。」

### So what? 所以呢？
Why does this matter for the research question, for design, for policy?
這對研究問題、設計、政策而言為何重要？
> "New public space design in that district should prioritize tree planting to close the equity gap." 「該區域新建公共空間設計應優先種植樹木，以縮小綠覆不均的落差。」

## The map is evidence, not the conclusion 地圖是證據，不是結論

A map shows *where* a pattern occurs. It does not, by itself, explain *why* or say *what should be done*. Treat every map as one piece of evidence supporting a written argument — never as the argument itself.
地圖顯示樣式**發生在哪裡**，但本身不會解釋**為什麼**，也不會說明**該怎麼做**。把每張地圖都當作支持書面論證的一項證據，而非論證本身。

## Worked example 範例演練

| Step | Content |
|---|---|
| What? 是什麼？ | Tree buffer coverage varies 15%–85% across public spaces. |
| Where? 在哪裡？ | Lowest coverage in the historic core; highest in post-2000 developments. |
| Why? 為什麼？ | Historic core has narrower streets and less planting space; newer development codes require street trees. |
| So what? 所以呢？ | Retrofitting tree planting in the historic core is a targeted, high-impact intervention — not a citywide blanket policy. |
