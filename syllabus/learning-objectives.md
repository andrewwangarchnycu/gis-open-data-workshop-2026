# Learning Objectives 學習目標

Organized by module. Each objective is written as "learners can…" 依模組整理，每項目標以「學習者能夠…」表述。

## 01 — Mapping the Unknown 探索未知空間

- Define GIS as a research method, not just a mapping tool.
  將 GIS 定義為一種研究方法，而非僅是製圖工具。
- Explain what "spatial thinking" means using an architectural example.
  以建築案例說明「空間思考」的意涵。

## 02 — From Space to Data 從空間到資料

- Distinguish vector vs. raster data models.
  區分向量與網格資料模型。
- Identify point, line, and polygon geometries in real spatial phenomena.
  在真實空間現象中辨識點、線、面幾何。
- Explain what an attribute table stores and why it matters.
  說明屬性表儲存的內容及其重要性。
- Explain coordinates and CRS (coordinate reference system) at a conceptual level.
  以概念層次說明座標與 CRS（座標參考系統）。

## 03 — Finding Open Geospatial Data 尋找開放地理資料

- Name at least three categories of open geospatial data sources.
  說出至少三類開放地理資料來源。
- Trace the logic from research question → required variables → dataset → source.
  從研究問題推導出所需變數、資料集與資料來源。
- Evaluate a dataset for spatial/temporal coverage and licensing before use.
  在使用前評估資料集的空間／時間涵蓋範圍與授權條款。

## 04 — QGIS Basics QGIS 基礎

- Load vector data (GeoJSON/CSV) into QGIS.
  將向量資料（GeoJSON／CSV）載入 QGIS。
- Inspect an attribute table and check a layer's CRS.
  檢視屬性表並確認圖層的 CRS。
- Apply a filter, buffer, spatial join, and intersection with a clear research rationale for each.
  執行篩選、緩衝區、空間 join 與交集，並為每個操作說明研究理由。
- Apply basic symbology to communicate a variable visually.
  運用基本符號化以視覺方式傳達變數。

## 05 — Computational GIS with Colab 用 Colab 做運算式 GIS

- Load a spatial dataset into GeoPandas in Google Colab.
  在 Google Colab 中以 GeoPandas 載入空間資料集。
- Inspect and clean a GeoDataFrame.
  檢視並清理 GeoDataFrame。
- Perform a spatial operation (buffer, join, intersection) in code.
  以程式碼執行空間運算（緩衝區、join、交集）。
- Calculate a derived spatial metric (e.g. density, count within area).
  計算衍生空間指標（例如密度、範圍內數量）。
- Visualize the result with Matplotlib.
  以 Matplotlib 視覺化結果。

## 06 — From Data to Spatial Insight 從資料到空間洞見

- Move from raw pattern to research interpretation using What/Where/Why/So-what.
  運用「是什麼／在哪裡／為什麼／所以呢」，從原始樣式推進到研究詮釋。
- Articulate that a map is evidence, not a conclusion.
  說明地圖是證據而非結論。

## 07 — Research Map Design 研究地圖設計

- Apply visual hierarchy so a viewer sees the key finding first.
  運用視覺層級，讓觀者先看到關鍵發現。
- Choose sequential, diverging, or categorical color schemes appropriately.
  適當選用連續型、發散型或類別型配色。
- Include essential map elements: title, legend, scale, north arrow, data source.
  納入地圖必要元素：標題、圖例、比例尺、指北針、資料來源。
- Annotate a map to highlight a specific spatial finding.
  於地圖上標註特定空間發現。

## 08 — One Map Challenge 一張地圖挑戰

- Independently produce one research map that states a question, shows an analysis, and communicates one insight.
  獨立產出一張研究地圖，陳述問題、呈現分析並傳達一項洞見。
