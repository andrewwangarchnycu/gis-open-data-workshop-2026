# Workshop Outline 工作坊大綱

**Mapping the Unknown: GIS, Open Data & Spatial Analysis**
探索未知空間：GIS、開放資料與空間分析

Duration 時長: **2 hours** ｜ Audience 對象: architecture graduates / early-stage spatial researchers 建築系畢業生／初階空間研究者

## Guiding idea 核心理念

> Don't start with a map. Start with a question.
> 不要從地圖開始，從問題開始。

> GIS is not only for making maps. GIS is a way to think spatially.
> GIS 不只是用來畫地圖，而是一種空間思考的方式。

## The pipeline 工作流程

```text
Research Question 研究問題
↓
Open Geospatial Data 開放地理資料
↓
GIS Exploration GIS 探索
↓
Computational Spatial Analysis 運算式空間分析
↓
Spatial Insight 空間洞見
↓
Research Map 研究地圖
```

## Prerequisites 先備需求

- A Google account (for Colab) Google 帳號（供 Colab 使用）
- QGIS installed (free, desktop-gis.org / qgis.org) 已安裝 QGIS（免費，qgis.org）
- No prior GIS or Python experience required 不需要先備 GIS 或 Python 經驗

## Deliverable 最終產出

One research map answering one spatial question, produced during the [One Map Challenge](../exercises/04_one_map_challenge/).
一張回答一個空間問題的研究地圖，於[一張地圖挑戰](../exercises/04_one_map_challenge/)中完成。
